API / MCP

Everything on this site comes from a public JSON API, and the same data is available to AI assistants through an MCP server. Both are free to use, need no key, and return the same numbers as the dashboard.

The data returned is © OpenStreetMap contributors, available under the Open Database License (ODbL). If you reuse or republish it, credit OpenStreetMap contributors as that page describes.

REST API

Plain HTTP GET with query parameters, JSON responses. Dates are UTC days (YYYY-MM-DD, end inclusive); without them, endpoints cover the last 7 days.

Base URL
/api/
OpenAPI schema
/api/schema/ (YAML; JSON)

Example: top editors of the last 7 days

curl '/api/changesets/toplist/?dimension=editor'

Full reference below, with a "Try it out" button on every endpoint.

MCP server

A Model Context Protocol server, so an assistant such as Claude can answer questions like "which editors created the most buildings in France last month?" from this data.

URL
/mcp
Transport
Streamable HTTP (stateless, JSON responses)
Authentication
None

Each tool is one REST endpoint, with the same parameters, limits and answers. The tools are listed below.

Connect an assistant

Claude (web, desktop, mobile)

Settings → Connectors → Add custom connector, name it "OSM Monitor" and paste the URL above. Then enable it in a conversation from the tools menu.

Claude Code

claude mcp add --transport http osm-monitor /mcp

Other MCP clients

Most take a JSON entry like this one:

{
  "mcpServers": {
    "osm-monitor": {
      "type": "http",
      "url": "/mcp"
    }
  }
}

Questions to start with: "How many changesets were made last week, and with which editors?", "Which hashtags changed the most objects this month?", "What are the most edited objects in Germany this week?"
